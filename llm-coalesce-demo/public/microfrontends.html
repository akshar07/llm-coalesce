How the bundles coordinate

Private registries make three requests. A shared windowAdapter() registry lets all three widgets subscribe to one in-flight stream within this browser page.

Module isolation and implementation details

Each widget imports llm-coalesce from its own /vendor/mfe-*/llm-coalesce/ URL. Browsers identify modules by resolved URL, so each import and its dependencies are evaluated as a separate module graph, with independent classes and closures.

The isolated side uses a private Map per adapter. The shared side passes windowAdapter() to coordinate through the page’s window object. This models independently bundled widgets and does not share state across tabs or server processes.

The repository includes a real-browser check for separate class identities, three isolated requests, one shared request, and identical subscriber output. See TUTORIAL-microfrontends-live-demo.md for the method.
