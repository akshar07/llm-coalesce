AFTER THE STREAM FINISHES

How sharing works

Matching requests share a registry while they are in flight. Turn on stagger to see late subscribers replay buffered chunks before joining the live stream. After completion, a new widget starts a fresh request.

Implementation and provider details

The browser loads the installed llm-coalesce package. Without coalescing, each widget opens its own SSE stream. With coalescing, coalescer.stream() invokes the stream factory once for the matching key and shares the result.

The server performs no request coalescing. The demo parses SSE in createSSEStream(); the library receives a plain async iterable and stays independent of the provider and transport.

The default mock needs no API key. For a real Anthropic completion, configure ANTHROPIC_API_KEY on the server as described in the repository. This comparison shares requests within one module graph; the microfrontends demo shows coordination across separate module graphs.
